# ⚔️ 도깨비의 세계 문파 분배 & 출석 자동화 시스템 (100% 무료 버전)

신용카드 등록이나 유료 결제 전혀 없이, **100% 완전 무료**로 구글 시트 자동 기록과 디스코드 스크린샷 닉네임 인식을 연동하는 시스템입니다.

## 📌 1. 구글 스프레드시트 수식 & 서식 가이드

제공해주신 시트: [구글 스프레드시트 바로가기](https://docs.google.com/spreadsheets/d/1HKKUt_nW6H01moxJwmjsdjGnEwOrKHj9Cy-AjYFWUC4/edit?gid=0#gid=0)

시트에 아래와 같이 서식과 수식을 넣어두시면, **총 재화만 수기로 적으면 전원 자동 계산**됩니다.

### 📊 시트 레이아웃 권장안

| 행/열 | A (닉네임) | B (참여 횟수) | C (분배 재화) |
|---|---|---|---|
| **1행** | **총 분배 재화 (수기 입력)** | **2500** *(문파장 입력란)* | |
| **2행** | **총 참여 횟수** | `=SUM(B6:B)` | |
| **3행** | **1회당 단가** | `=IF(B2>0, INT(B1/B2), 0)` | |
| **4행** | **분배 총액 / 잔여** | `=SUM(C6:C)` | `=B1-B4` *(자투리 잔여액)* |
| **5행 (헤더)** | **문파원 닉네임** | **참여 횟수 (자동)** | **분배 예정 재화 (자동)** |
| **6행~** | 문파원A | 1 | `=IF($B$2>0, INT($B$1 * (B6 / $B$2)), 0)` |
| 7행 | 문파원B | 1 | `=IF($B$2>0, INT($B$1 * (B7 / $B$2)), 0)` |
| 8행 | 문파원C | 1 | `=IF($B$2>0, INT($B$1 * (B8 / $B$2)), 0)` |
| 9행 | 문파원D | 2 | `=IF($B$2>0, INT($B$1 * (B9 / $B$2)), 0)` |

> 💡 **Tip (수식 자동 채우기)**:
> C6 셀 하나에만 아래의 `MAP` 함수를 넣어두면, 아래로 드래그하지 않아도 인원이 추가될 때마다 자동으로 분배 재화가 계산됩니다:
> ```excel
> =MAP(B6:B, LAMBDA(cnt, IF(AND(ISNUMBER(cnt), cnt>0, $B$2>0), INT($B$1 * (cnt / $B$2)), 0)))
> ```

## 🚀 2. 신용카드/결제 없는 100% 무료 연동 세팅 (3단계)

### Step 1. 구글 시트에 Apps Script 등록 (GCP/카드 불필요! 2분 소요)
1. 사용 중이신 구글 시트 상단 메뉴에서 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
2. 에디터에 기존 코드가 있다면 지우고, 이 폴더의 [apps_script.js](file:///c:/dokkaebi/apps_script.js) 파일 전체 내용을 복사해서 붙여넣습니다.
3. 상단 **💾 저장(디스크 아이콘)**을 클릭합니다.
4. 우측 상단 파란색 **[배포] > [새 배포]**를 클릭합니다.
5. 좌측 톱니바퀴 아이콘을 눌러 **[웹 앱]**을 선택합니다.
   - **설명**: `도깨비봇`
   - **다음 사용자 이름으로 실행**: `나(내 이메일)`
   - **액세스 권한이 있는 사용자**: **`모든 사용자(Anyone)`** 선택 *(필수)*
6. 하단 **[배포]** 클릭 후, 권한 승인 창이 뜨면 **[액세스 승인]** > 본인 구글 계정 선택 > **[고급]** 클릭 > **`...으로 이동(안전하지 않음)`** 클릭 > **[허용]**을 누릅니다.
7. 화면에 나오는 **`웹 앱 URL`**(예: `https://script.google.com/macros/s/AKfycb.../exec`)을 복사합니다.

### Step 2. 무료 Gemini API 키 발급 (신용카드 불필요!)
Google AI Studio의 Gemini 무료 티어는 **신용카드 등록 없이** 구글 계정만 있으면 발급되며, **완전 무료**입니다.
- **무료 한도**: 하루 최대 1,500회 요청 (문파 스크린샷 수십 장은 평생 무료)
1. [Google AI Studio](https://aistudio.google.com/app/apikey) 접속 (구글 로그인)
2. **[Create API key]** 버튼 클릭
3. 생성된 API 키를 복사합니다.

### Step 3. 디스코드 봇 토큰 발급 및 `.env` 파일 작성
1. [Discord Developer Portal](https://discord.com/developers/applications) 접속
2. **New Application** 생성 후 좌측 **Bot** 탭으로 이동
3. **Privileged Gateway Intents** 섹션에서:
   - ✅ **MESSAGE CONTENT INTENT** 활성화 (필수)
4. **Reset Token**을 눌러 봇 토큰 복사
5. 좌측 **OAuth2 > URL Generator**에서:
   - Scopes: `bot`
   - Bot Permissions: `Send Messages`, `Embed Links`, `Attach Files`, `Read Message History`
   - 생성된 URL로 봇을 본인의 디스코드 서버에 초대
6. `c:\dokkaebi\.env.example` 파일을 복사하여 `.env`로 이름을 바꾼 후 키를 입력합니다:
   ```ini
   DISCORD_BOT_TOKEN=디스코드_봇_토큰
   DISCORD_CHANNEL_ID=  # 스크린샷 채널 ID (비워두면 모든 채널 감지)
   GAS_WEBAPP_URL=https://script.google.com/macros/s/AKfycb.../exec
   GEMINI_API_KEY=발급받은_Gemini_API키
   ```

## 🎮 3. 봇 실행 및 명령어

바탕화면이나 폴더에서 `외길문파_봇_실행하기.bat`을 더블 클릭하면 디스코드 봇이 실행됩니다!

| 명령어 | 설명 | 예시 |
|---|---|---|
| *(스크린샷 업로드)* | 이미지를 올리면 자동으로 닉네임을 감지해 참여 +1 반영 | 스크린샷 첨부 |
| `!현황` (또는 `!목록`) | 현재 등록된 문파원들의 누적 참여 횟수 순위 조회 | `!현황` |
| `!수동추가 [닉네임] [컨텐츠]` | 스크린샷 누락/미인식 시 특정 컨텐츠 체크박스 수동 체크 | `!수동추가 홍길동 신기` |
| `!문파원추가 [닉네임]` | 새로운 문파원이 가입했을 때 시트에 바로 등록 | `!문파원추가 도깨비` |
| `!초기화` | [관리자 전용] 분배 주기 종료 후 전원 참여 횟수 0으로 리셋 | `!초기화` |
| `!도움말` | 명령어 도움말 확인 | `!도움말` |
